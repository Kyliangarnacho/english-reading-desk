# English Reading Desk

Personal reading materials for the 2027 Chinese postgraduate English examination.

Responsive English reading, sentence structure colors, literal Chinese translations, and a searchable vocabulary collection. No sign-in is required to read this site. Bookmarks and display settings stay in the visitor's browser.

This repository contains the published static website. Articles retain their original sources and license notices. Bootstrap 5.3.8 is MIT-licensed; Lucide icons are ISC-licensed. License texts are included in `vendor/`.

GitHub Pages publishes the `main` branch root. All browser assets are served from this repository without runtime CDN dependencies.
